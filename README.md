# Ederito Digital Studio Website

A new static website concept for Ederito, operated by Zanara Labs LLC. The design is intentionally different from the existing ederito.com website.

## Included

- Premium responsive one-page agency website
- Portfolio links for Koneksyon, Becoming Training Center, Belle Créole Kwizin, Usoutt and Greg Promo
- Koneksyon website + mobile application showcase
- Services for websites, apps, business launch support, branding, flyers and maintenance
- Project request form that prepares an email to `contact@ederito.com`
- Client review form that prepares an email to `contact@ederito.com`
- Privacy Policy and Terms starter pages
- Mobile navigation, scroll animation and responsive layouts
- Ederito logo assets and favicon

## Preview locally

Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Deploy

The folder can be uploaded to GitHub Pages, Cloudflare Pages or another static host. For Cloudflare Pages, use no build command and set the output directory to the project root.
